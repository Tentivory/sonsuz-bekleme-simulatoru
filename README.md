# Sonsuz Bekleme Simülatörü

## Giriş

Bu proje, insanlığın en temel deneyimlerinden birini — beklemek — mükemmel bir şekilde simüle etmek için tasarlanmıştır. Modern dünyada her şey hızlı olmak zorunda değildir. Bazen sadece oturup beklemelisiniz. Bu simülatör, o bekleyişi sanatsal bir zirveye taşır.

### Neden Var?

Çünkü hayat bir bekleme odasıdır. Kargo gelmez, randevu ertelenir, "bir dakika" asla bir dakika olmaz. Bu program, o gerçeği kod ile kutsar.

## Kullanım

```bash
python sonsuz_bekleme.py
```

Program başladığında durmaz. Durursa bir şeyler yanlış gitmiştir. Beklemeye devam edin.

## Özellikler

- %99.999999 sonsuza kadar yüklenir
- Felsefi yorumlar üretir
- Gerçek zamanlı mazeretler
- Hiç bitmez (bu bir özelliktir)

## Lisans

Bekleme lisansı altında. İstediğiniz kadar bekleyebilirsiniz.
